# Bomb Crypto (BCOIN) V2 - Whitepaper

Interactive whitepaper and documentation site for Bomb Crypto (BCOIN) V2, built by the Senspark team.

## Tech Stack

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/) + TypeScript
- [shadcn/ui](https://ui.shadcn.com/) + [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:8080`.

## Build

```bash
npm run build
```
